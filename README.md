# 1С «Управление магазином»

Проект на платформе 1С:Предприятие 8.3,
разработанный с использованием Библиотеки стандартных подсистем (БСП).

## О проекте

Конфигурация предназначена для автоматизации основных операций
небольшого магазина: работы с товарами, поставщиками, клиентами,
складского и оперативного учета.

## Реализовано

- справочники товаров, контрагентов и организаций;
- загрузка каталога товаров из XML;
- работа с БСП.

## Технологии

- 1С:Предприятие 8.3
- БСП
- управляемое приложение
- язык запросов 1С
- загрузка данных из Excel

## Назначение проекта

Проект для демонстрации навыков разработки
конфигураций на 1С:Предприятие 8.3.
